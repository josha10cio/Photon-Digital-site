# Repository Structure Summary

## Top-Level Directories
- `.git` — Git metadata for version control.
- `.next` — Next.js build output and cache generated by `next build` / `next dev`.
- `.obsidian` — Obsidian vault metadata (notes/workspace settings).
- `app` — Next.js App Router source: routes, layouts, and pages (e.g., `/contact`, `/services`, `/insights`, `/api/contact`).
- `components` — Shared React components; includes a large `components/ui` library (Radix + shadcn-style primitives) and site-specific components like header/footer.
- `content` — Markdown content; currently `content/insights` contains article drafts and a README.
- `docs` — Content strategy and SEO/structure docs (audits, outlines, metadata).
- `hooks` — Custom React hooks (e.g., `use-mobile`, `use-toast`).
- `lib` — Small shared utilities (e.g., `utils.ts`).
- `node_modules` — Installed dependencies (generated by npm/pnpm).
- `public` — Static assets served by Next.js (images, PDFs, video, favicon, robots.txt, sitemap.xml).

## Architecture Summary
This is a Next.js 15 App Router project with Tailwind CSS and a sizeable shadcn/Radix UI component library. Pages and routes live under `app`, including a serverless API endpoint at `app/api/contact/route.ts` that sends email via `nodemailer` using environment-configured SMTP. Static assets are served from `public`. Markdown content for “Insights” lives under `content/insights` and appears to be intended for future rendering, while the current `app/insights` page is a static placeholder. Supporting UI primitives live in `components/ui`, with shared layout components in `components`, plus a small set of utilities and hooks in `lib` and `hooks`.
